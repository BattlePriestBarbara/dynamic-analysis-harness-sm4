# 00 摘要与结论分级

## 0.1 这份文档回答什么

它记录一次完整的 Android 客户端逆向：从拿到解包目录，到把壳的 native 代码在仿真器里跑起来，
再到把国密 SM4 的取数链路逐跳定位、最后卡在一个**结构性的取数阻塞**上。

它同时是一份**方法论记录**：哪些结论经得起复核，哪些只是"看起来对"，
以及三次误判是怎么被发现并撤销的（见 [12](12-经验与教训.md)）。

## 0.2 结论分级约定

| 级别 | 含义 | 判定标准 |
|---|---|---|
| **已证** | 有可复跑的测量值支撑 | 有具体命令 + 具体输出 + 具体文件 |
| **较强** | 多条独立证据同向，但缺一条闭合 | 至少 2 条互相独立的测量，且不依赖同一假设 |
| **推断** | 从形态合理推出，未测量 | 文中显式标注"推断"，不得作为结论引用 |
| **证伪** | 曾有解释被测量推翻 | 必须写明"原假设 + 推翻它的那个数字" |

报告中任何数字都应是**实测**；凡未标注的"可能会/应该是"一律视为推断。

## 0.5 明确**不能**当结论用的说法

1. "风控 SDK 会上传用户省份/城市" —— 字符串与调用点存在，但**上报开关与字段是否真被填充未观测**。
2. "存在代码级证书绑定" —— 只能证明**声明式配置**里没有 pin-set；主 DEX 不可读，所以不能断言"没有 pinning"。
3. "这 80 字节是签名" —— 只是"看起来像二进制签名"，未被验证。
4. "索引缺口是一份保护名单" —— 已被形状证伪（见 [08](08-APK内部索引缺口.md)），不要复活这个说法。
5. "仿真结果等于真机行为" —— 仿真器绕过了启动期校验，因此**一切运行时结论都只在"过了校验之后"的语境下成立**。
