# 99 附录：术语与地址速查

## 99.1 术语表

| 术语 | 含义 |
|---|---|
| **SMC**（Self-Modifying Code） | 自我修改代码：启动时把密文解密写回自身代码段并刷新 icache |
| **`DT_INIT` / `DT_INIT_ARRAY`** | ELF 的初始化函数 / 初始化函数指针数组，加载时由 linker 调用 |
| **`DT_HASH`** | ELF 的哈希表，Android linker 用它找符号（**不看节头**） |
| **节头伪造** | 故意让 `.dynsym` 的 `sh_size` 远小于真实值，误导静态工具 |
| **CFF**（Control-Flow Flattening） | 控制流平坦化：把直线代码切成块，用状态机串起来 |
| **VMP** | 虚拟机保护：把原生指令改写成自定义字节码，由解释器执行 |
| **PA**（Protected App） | 沙箱化运行环境；`flags` 含 `microdroid` 时可在 pKVM 虚拟机内运行 |
| **AVF / pKVM / MicroDroid** | Android 虚拟化框架 / 受保护的 KVM / 其上的精简 Android 载荷 |
| **deflate** | ZIP 常用压缩算法；其数据内部可能**恰好**含 `PK\x03\x04` 字面量（见 [08 §8.4](08-APK内部索引缺口.md)） |
| **局部头 / 中央目录（CD）** | ZIP 的每条目头 / 文件末尾的总目录 |
| **PKCS#7** | 此处指填充方案（解密后尾部应有合法结构，可作为"解对了"的判据） |
| **gate（闸门）** | 壳内置的"资产是否存在于内部索引"的检查函数 |
| **reader** | 闸门之后真正读取条目字节的函数（两条实现） |
| **`dec_BEwords`** | 本项目定义的 SM4 解密约定：大端字序，正序使用**反转后**的轮密钥 |
| **诱饵（decoy）** | 刻意放出的无效产物（如 156 B 的 `class_defs=0` DEX） |

## 99.6 地址换算

```
镜像地址  = 文件偏移 + 0x12000000
Ghidra 地址 = 镜像地址 − 0x12000000 + 0x100000  =  文件偏移 + 0x100000
```

例：文件偏移 `0x82f48` → 镜像 `0x12082f48` → Ghidra `0x182f48`。

> 报告里凡是出现裸地址，都必须能按上式换算；出现 `0x18xxxxx` 时说明是在 Ghidra 里读的。
